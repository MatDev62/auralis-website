Política de privacidade da integração de backup (aplicativo OAuth “rclone”)

Última atualização: 6 de novembro de 2026

1. A quem se aplica

Esta política se aplica ao aplicativo OAuth “rclone” registrado pelo responsável pelo projeto Auralis. A integração é de uso pessoal e privado: é utilizada somente pelo próprio responsável, com a própria conta Google, e não é oferecida a outras pessoas.

2. Dados do Google acessados

A integração solicita apenas o escopo https://www.googleapis.com/auth/drive.file. Esse escopo dá acesso somente aos arquivos e pastas do Google Drive criados por este aplicativo, ou abertos e compartilhados explicitamente com ele. Os demais arquivos da conta não ficam acessíveis à integração.

3. Como os dados são usados

O acesso é usado exclusivamente para gravar, listar, ler e manter os arquivos de backup privados do projeto Auralis no Google Drive do responsável, por meio do programa Rclone executado no computador do responsável. Não há outra finalidade.

4. Onde os dados ficam

Os arquivos de backup ficam armazenados na conta Google Drive do próprio responsável. As credenciais de autorização ficam somente no computador em que o Rclone é executado. Nenhum dado do Google Drive é enviado a este site ou a servidores mantidos pelo projeto Auralis.

5. Compartilhamento

Os dados acessados pela integração não são vendidos, cedidos ou compartilhados com terceiros. Eles são processados apenas pelo Google, como provedor do Google Drive, e pelo Rclone em execução local.

6. Remoção e revogação

O responsável pode remover os arquivos de backup diretamente no Google Drive e revogar a autorização a qualquer momento em myaccount.google.com/permissions. Após a revogação, a integração deixa de ter acesso à conta.

7. Este site

Este site é estático. Não usa formulários, cookies próprios nem ferramentas de análise de visitas. O serviço de hospedagem pode registrar dados técnicos de acesso conforme as políticas do próprio provedor.

8. Alterações

Mudanças nesta política serão publicadas nesta página, com a data de atualização.

9. Contato

Dúvidas sobre esta integração OAuth ou sobre esta política de privacidade podem ser enviadas para auralisgame@gmail.com.

English version

Scope of this policy. This policy covers the “rclone” OAuth application registered by the owner of the Auralis project. It is a personal, private integration used only by the owner, with the owner’s own Google account, and is not offered to anyone else.

Google data accessed. The integration requests only https://www.googleapis.com/auth/drive.file, which gives access only to Google Drive files and folders created by, opened with, or explicitly shared with this application.

Use. Access is used solely to write, list, read and maintain private backup files of the Auralis project in the owner’s Google Drive, through the Rclone program running on the owner’s computer.

Storage. Backup files are stored in the owner’s Google Drive. Authorization credentials are kept only on the computer that runs Rclone. No Google Drive data is sent to this website or to any server operated by the Auralis project.

Sharing. Data accessed by the integration is not sold, transferred or shared with third parties. It is processed only by Google, as the Google Drive provider, and by Rclone running locally.

Removal and revocation. The owner can delete the backup files in Google Drive and revoke the authorization at any time at myaccount.google.com/permissions.

This website. This is a static site with no forms, no first-party cookies and no analytics. The hosting provider may log technical access data under its own policies.

Changes. Changes to this policy will be posted on this page with the update date.

Contact. Questions about this OAuth integration or this privacy policy can be sent to auralisgame@gmail.com.
