Integração de backup com o Google Drive (aplicativo OAuth “rclone”)

Esta página descreve o aplicativo OAuth chamado “rclone”, registrado pelo responsável pelo projeto Auralis para uso pessoal. Ele permite que o programa de código aberto Rclone, executado no computador do próprio responsável, grave e leia cópias de segurança privadas do projeto na conta Google Drive desse mesmo responsável.

O Rclone é um software independente, desenvolvido e mantido por seus próprios autores. Esta integração não é um produto do Rclone, não foi criada pelos desenvolvedores do Rclone e não tem vínculo oficial com eles. O nome do aplicativo apenas identifica o programa que utiliza a autorização.

Finalidade

Armazenar no Google Drive do responsável os backups privados dos arquivos de desenvolvimento do Auralis. A integração não é oferecida ao público e não se destina a outros usuários.

Acesso solicitado

A integração solicita somente o escopo https://www.googleapis.com/auth/drive.file. Com ele, o acesso fica limitado aos arquivos e pastas criados por este aplicativo, ou abertos e compartilhados explicitamente com ele. Não há acesso ao restante do conteúdo do Google Drive.

Como funciona

A autorização é concedida pelo próprio responsável na tela de consentimento do Google. As credenciais resultantes ficam somente no computador em que o Rclone é executado. Este site não recebe, processa nem armazena dados do Google Drive.

English summary

“rclone” is a personal OAuth application registered by the owner of the Auralis project. It lets the open-source Rclone program, running on the owner’s own computer, store private backups of the project in the owner’s own Google Drive. It requests only the drive.file scope, which limits access to files created by, opened with, or shared with this application. It is not offered to the public. Rclone is independent software; this integration is not affiliated with or endorsed by the Rclone developers. See the privacy policy.
